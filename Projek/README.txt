website Portofolio DD

Website Portofolio pribadi Dede Bintang Gafendi, Mahasiswa Informatika Universitas Andalas. Proyek ini dibangun menggunakan Bootstrap 5 untuk memastikan desain yang responsif, modern, dan kompatibel dengan tema Dark Mode dan Glassmorphism.

1. FITUR UTAMA


* **Filter Portofolio Dinamis:** Menggunakan JavaScript dan transisi CSS untuk memfilter proyek (UI/UX, Web Dev, Mobile) secara halus.
* **Modal Detail Proyek:** Kartu portofolio dapat diklik untuk menampilkan detail proyek spesifik (gambar, judul, deskripsi) melalui Modal yang diisi secara dinamis.
* **Validasi Formulir Kontak:** Formulir kontak dilengkapi dengan validasi client-side Bootstrap yang ketat dan notifikasi Toast Sukses saat pengiriman.
* **Komponen Interaktif:** Implementasi Carousel (Design Gallery) dan Accordion (Riwayat Hidup & Skills).
* **Desain Modern:** Mengadopsi tema Dark Mode dan elemen Glassmorphism (pada Navbar dan Form).


2. STRUKTUR PROYEK

DD-Portofolio/
├── index.html         # Halaman Utama (Home, Services, Gallery)
├── about.html         # Halaman Tentang Saya (Info Pribadi, Timeline, Accordion)
├── portofolio.html    # Halaman Grid Portofolio (Filter & Modal)
├── contact.html       # Halaman Kontak (Form, Info Kontak, Maps)
├── styles.css         # File CSS Kustom (Dark Mode, Glassmorphism, Custom Styles)
├── js/                # (Direktori untuk JavaScript kustom)
└── assets/            # (Direktori untuk gambar, SVG, dll.)
